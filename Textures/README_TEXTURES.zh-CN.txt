EMOTEHUB 纹理 - TGA 图像指南
===========================

此文件夹用于存放 EmoteHub 图标的 TGA 纹理文件。


必需文件：
=========

要让插件显示自定义图标，请将下列 TGA 文件放入此文件夹：

- wave.tga      （挥手表情）
- hug.tga       （拥抱表情）
- dance.tga     （跳舞表情）
- kiss.tga      （亲吻表情）
- flirt.tga     （调情表情）
- sit.tga       （坐下表情）
- sleep.tga     （睡觉表情）
- bow.tga       （鞠躬表情）
- cheer.tga     （欢呼表情）
- cry.tga       （哭泣表情）
- laugh.tga     （大笑表情）
- point.tga     （指向表情）
- salute.tga    （敬礼表情）
- shy.tga       （害羞表情）
- thank.tga     （致谢表情）
- yes.tga       （同意表情）


TGA 格式要求：
==============

- 格式：TGA（Targa Image Format）
- 推荐尺寸：32x32 像素
- 其他尺寸：64x64 或 128x128 像素也可用
- 颜色深度：24 位（RGB）或 32 位（RGBA，含透明通道）
- 压缩：不压缩或 RLE 压缩
- 文件扩展名：必须为 .tga（推荐小写）


制作 TGA 文件：
===============

方法 1：GIMP（免费）
1. 打开 GIMP
2. 新建 32x32 像素图像
3. 设计图标
4. 选择“文件” → “导出为” → [filename].tga
5. 在导出对话框中选择“24 位”或“32 位”
6. 点击“导出”

方法 2：Paint.NET（免费）
1. 打开 Paint.NET
2. 新建 32x32 像素图像
3. 设计图标
4. 选择“文件” → “另存为”，再选择 TGA 格式
5. 使用 .tga 扩展名保存

方法 3：Photoshop
1. 新建 32x32 像素文档
2. 设计图标
3. 选择“文件” → “存储为” → Targa (*.TGA)
4. 选择每像素 24 位或 32 位

方法 4：从 WoW 提取
使用以下工具：
- WoW Model Viewer
- WoW Export Tools
- MPQ Editors
用这些工具提取现有游戏图标，并转换为 TGA 格式


设计建议：
=========

- 小尺寸下保持设计简单、易辨认
- 使用高对比度颜色，确保可见
- 选择颜色时考虑深色 UI 背景
- 需要时，用 32 位 TGA 测试透明效果
- 图标保持正方形（宽高相同）


图标来源：
=========

可以制作以下图标：
- 手势（挥手、指向等）
- 面部表情（微笑、哭泣等）
- 身体姿势（鞠躬、坐下、跳舞）
- 表示情绪的抽象符号
- 简化人物姿势
- 自定义艺术表达


排错：
=====

图标不显示？
- 检查文件名是否完全一致（区分大小写）
- 确认文件位于此 Textures 文件夹
- 确保 TGA 格式正确（24/32 位）
- 添加新文件后重启 WoW

图标显示损坏？
- 重新保存为不压缩 TGA
- 尝试其他位深（24 位或 32 位）
- 检查图像尺寸是否正确

文件大小问题？
- 32x32 TGA 文件应较小（每个约 4 KB）
- 尺寸越大，内存占用越高
- 为获得最佳性能，请使用推荐的 32x32 尺寸


回退行为：
==========

如果 TGA 文件缺失，EmoteHub 将显示：
- 默认问号图标
- 按钮仍可使用表情命令
- 不会显示视觉错误，只显示通用占位图标


高级自定义：
============

要使用其他表情或添加更多按钮：
1. 编辑 EmoteHub.lua 文件
2. 修改 EmoteHub.emotes 表
3. 将对应的 TGA 文件添加到此文件夹
4. 更新 Lua 文件中的图标路径

警告：修改前备份文件！


优质 TGA 图标示例：
===================

- 设计简单、醒目
- 在 32x32 分辨率下清晰
- 配色合适
- 符号或手势易辨认
- 所有图标风格一致

祝自定义愉快！
